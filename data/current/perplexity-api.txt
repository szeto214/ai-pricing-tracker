Orchestrator API Pricing
Orchestrator API usage is billed per token at each model’s published rates, with no per-request fees. Every model has its own input and output rate, with cache reads billed at the model’s cache-read rate and reasoning tokens billed at the output rate. Some models also charge for cache writes; see
Orchestrator billing
. You are billed at the requested model’s rates regardless of which deployment serves the request; with
perplexity/auto
, at the rates of the model that served it.
See
Orchestrator Models & Pricing
for the full per-model rate card, including cache-read rates and usage tiers.

priority

google/gemini-3.7-flash

Token and Cost Glossary
Input Tokens
The number of tokens in your prompt or message to the API. This includes:
Your question or instruction
Any context or examples you provide
System messages and formatting
Tool results that the API passes to the model
Example:
“What is the weather in New York?” = ~8 input tokens
Output Tokens
The number of tokens in the API’s response. This includes:
The generated answer or content
Any explanations or additional context
Example:
“The weather in New York is currently sunny with a temperature of 72°F.” = ~15 output tokens
Token Calculation:
1 token ≈ 4 characters in English text. The exact count may vary based on language and content complexity.
