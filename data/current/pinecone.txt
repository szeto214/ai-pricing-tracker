How database billing works
Document indexes (the Documents API) and vector indexes are billed the same way, on four meters: storage, reads, writes, and egress. Rates and plan limits are in the
plan comparison table
below.
Storage
Measured in GB across all your records. In a document index, record size counts every field in the schema, including vectors and text, plus metadata and the record ID.
Reads
A query or a full-text search uses 1 read unit per GB of the namespace it searches, with a minimum of 0.25. The number of results returned does not change the cost. A hybrid search sent as one request counts once. Two searches merged in your code count twice. On Dedicated Read Nodes, reads are a fixed hourly rate instead.
Writes
An upsert uses 1 write unit per KB of the request, with a minimum of 5 per request. An upsert or update that replaces an existing record also counts that record's size. Batching records into fewer requests avoids paying the minimum on each one.
Egress
Measured in GB of data returned to you by reads such as query, fetch, list, and search. Every plan includes a monthly allowance. Writes, index stats, and index management are not counted.

Frequently asked questions
How is the Documents API priced?
The same way as vectors. Document indexes use the same storage, read, write, and egress rates as vector indexes. Storage counts every field in the document's schema, including vectors and text, plus metadata and the record ID.
Does full-text search cost extra?
No. A full-text search is billed in read units like any query: 1 read unit per GB of the namespace searched, with a minimum of 0.25. Full-text search is available on every plan, including Starter.
How is hybrid search billed?
By the number of searches it runs. Filtering by text match and then ranking by vector is one search. Separate keyword and vector searches merged in your application are billed as two.
How is integrated embedding billed?
When Pinecone embeds a text field for you, embedding is billed separately by the number of tokens, both for the text you upsert and for query text. A retried or duplicate write is embedded and billed again. The field's text counts toward storage unless the field sets store_text to false. Then only the generated vector counts.
How is pg_pinecone priced?
The extension is free and open source under Apache 2.0. With the native engine, search runs inside your own Postgres server and never calls Pinecone. If you have Pinecone generate the embeddings, those are billed by tokens. The remote engine keeps a Pinecone serverless index in sync with your table and searches it there. That index is billed like any other. See
pg_pinecone
in the docs.
How does query cost change as my data grows?
Read units per query depend on the size of the namespace you search. A 10 GB namespace uses 10 read units per query. The number of results and the fields returned do not change the count. Splitting data into namespaces, for example one per tenant, keeps each search smaller. For large indexes with steady, high traffic, Dedicated Read Nodes charge a fixed hourly rate for read capacity instead of per read.
What does the Standard plan's $50 minimum mean?
Standard bills at least $50 a month. Your usage counts toward that amount. Anything above it is billed at the pay-as-you-go rates. Starter and Builder organizations can try Standard for 3 weeks with $300 in credits.
What happens when I reach the Starter or Builder limits?
Starter and Builder include monthly allowances of reads, writes, and egress, plus a storage cap. Usage past a monthly allowance is blocked rather than billed until it resets at the start of the next billing period, or until you upgrade. Standard and Enterprise have no monthly usage caps and bill what you use.
How do I estimate my monthly cost?
Use the
pricing calculator
. It takes your record count, vector dimensions, metadata size, namespaces, and monthly queries and writes. It estimates both On-Demand and Dedicated Read Nodes. For a document index, add the average text per record to the metadata size, since text counts toward storage the same way. The formulas are in
Understand Pinecone cost
in the docs.
